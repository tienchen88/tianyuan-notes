Cole Medin：讓 coding agent 剪片的那個 skill，重點在最後那 10%

晚上照例去看 Cole Medin 有沒有新片，今天這支是 This Skill Turns Claude Code Into an Expert Video Editor。他說這支影片本身就是他的 agent 剪的，然後把那個 edit video skill 免費放出來。

一樣先講，我是看字幕整理的，畫面上的剪接效果、那些前後對照，我只能從他的描述去想像，repo 也還沒點進去看。

他講了什麼

開頭那段我蠻有感的。他說不用 skill，直接把素材丟給 agent 叫它剪，其實也能做到九成。麻煩的是剩下那一成，一堆細碎的小問題來回修，最後花的時間比自己剪還多。這個 skill 就是在處理那一成。

核心流程五步，不管什麼類型的片都會走：

  1. 轉逐字稿，每個字都有時間戳，順便找出重錄的段落
  2. 剪掉空白、換氣、重複的字
  3. 把剩下的片段接起來
  4. 加轉場和動畫
  5. 輸出，最後檢查一輪，有問題就回頭改

每一步背後都有一支小腳本。他的說法是，LLM 自己聽不到聲音、也看不懂影片哪裡是空檔，所以由腳本把時間戳之類的資料算好丟回去，主 agent 只負責做決定。剪完之後還有一支驗證腳本，把成品重新轉一次逐字稿，跟原始逐字稿逐字比對，確認真的剪在對的地方。

不同類型的內容（全臉、螢幕加小臉框、短影音、課程）他用一張表來對應，每一種都只是那幾個步驟的組合，不用每種從頭寫一遍。你沒講清楚要什麼，它會先問。

lessons.md 跟 brand.json

他說最該自己改的有兩個。brand.json 放動畫的品牌色，這個很直觀。另一個是 lessons.md，那些還不到要寫一支腳本的小毛病，就用白話文記在裡面，下次比較不會再犯。他說這是他「被咬過的地方」的大雜燴。

進階版是透過 OpenRouter 接多模態模型，補上 agent 做不到的四件事：聽、看影片、生圖、複製聲音。他舉的例子有抓出錄音時 CPU 太忙造成的細微卡頓、用聲音複製把講錯的 70% 改成 75%，還有做縮圖跟從長片切短影音。一整支片用進階版跑下來他說大約 2.71 美元。

我的想法

老實說我不剪片，吸引我的是那個拆法。主 agent 負責判斷，算得出來的事交給腳本，剪完再用另一種方式驗一次。這跟前兩天那支講驗證的片有點接得上，檢查要是 agent 自己控制不了的東西。

lessons.md 這招我覺得最好偷。我自己也常遇到同一個小錯誤一直重來，每次都想說下次記得，然後就沒有然後了。寫一份檔案專門記這種小事，聽起來很土，但大概是最有用的。

聲音複製改數字那段，我有點猶豫。技術上很厲害，可是改完觀眾完全聽不出來，這件事我還沒想好自己怎麼看。

repo 有空再去翻，看那些腳本實際長什麼樣子。
