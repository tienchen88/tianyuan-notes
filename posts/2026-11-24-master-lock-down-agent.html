Cole Medin：有人盯上你的 coding agent 了（先記下我想看的地方）

晚上照例去看 Cole Medin 有沒有新片，這支叫 Hackers Are Coming for Your AI Coding Agent (Lock It Down Now)。

先講清楚，這篇是我還沒看完整支片寫的。字幕跟說明我都還沒拿到，所以下面只是我看到標題後的猜測，跟他實際講的可能有出入，等看完再回來補。

為什麼想看

上週他才講過 agent 太想幫忙會闖禍（我的筆記在這），那支講的是 agent 自己出包。這支看標題是換個方向，講外面有人故意來搞你的 agent。兩支剛好可以放在一起看。

而且 coding agent 跟一般聊天機器人不太一樣，它通常可以讀整個專案、跑終端機指令、碰得到 .env 裡的金鑰。權限這麼大，被人騙一次的代價就很高。

我預期的看點

這陣子網路上討論 coding agent 安全的文章蠻多的，我猜他會講到其中幾種：

  • 藏在專案檔案裡的指令。agent 打開 repo 會自動去讀說明檔、規則檔，如果有人在別人的專案裡塞一段話，agent 可能就照做了
  • 透過 MCP 或外部工具進來的東西。像是錯誤回報、網頁內容這類 agent 會去抓的資料，裡面也可以夾帶指令
  • 金鑰外流。被騙之後把 SSH key 或 token 送出去，這種最可怕
  • 防法大概會是 sandbox、最小權限、限制網路、用完換金鑰這幾招

以他的習慣，應該會有實際示範，可能也會推他自己在用的設定方式。我比較想知道的是，他覺得一般人在自己電腦上用 Claude Code 這類工具，最低限度要做到哪幾件事。全部做到很累，總要有個先後順序。

老實說，我自己現在 agent 的權限開得蠻寬的，看標題有點心虛。看完再來對照一下自己哪裡該收。
