純視覺機器人導航：一顆相機、五個版本的進化史

做過的一個機器人導航題目，限制很有趣：模擬場景裡有彩色方塊當障礙、終點是一座拱門，而機器人只有一顆 RGB 相機——沒有光達（沒距離）、沒有里程計（不知道自己在哪）、也不用 AI 模型。感知只剩 OpenCV 的 HSV 色彩遮罩：黑色遮罩（V≤25，順便過濾陰影）抓拱門，高飽和遮罩（S≥120）抓障礙方塊。

這篇把五個版本的進化史記下來。每一版都不是「想到新功能」，而是被一種具體的失敗逼出來的。

v1.0：原地死轉——探索也需要動力

第一版邏輯很天真：看到目標就朝它走，沒看到就原地旋轉找。結果機器人在空曠地轉了一圈什麼都沒看到，就永遠轉下去了——經典的 local minima。

解法出乎意料地簡單：巡邏模式加上前進速度（linear.x = 0.2），邊轉邊走。探索不是旋轉，是移動。原地旋轉只能改變視角，不能改變視野。

v2.0：盲區撞牆——相機看不到腳下

第二版解兩個問題。一是避障太僵硬：看到障礙就急煞原地轉，走起來一頓一頓。引入人工勢場的概念，中距離改成平滑繞行（前進 0.15 m/s 同時帶轉向），路徑變成弧線。

二是更隱蔽的：相機有俯角盲區，障礙物一旦近到進入畫面下緣以下，遮罩上就「消失」了，機器人誤判安全直接輾上去。解法是觸底偵測——障礙物的 bounding box 底邊超過畫面高度減 180px，就當作已經頂到輪子，觸發「全力倒車＋反向猛打方向盤」的脫困程序。

感測器的盲區不會回報「我看不到」，它會回報「這裡沒東西」。這兩者的差別會撞出來。

v3.0：把拱門看成兩根柱子——FOV 裁切問題

靠近拱門時出現詭異行為：機器人明明該穿門而過，卻朝著門柱撞上去。原因是視野裁切（FOV clipping）——距離近了，拱門在畫面裡被切成兩個獨立的黑色輪廓，「朝最大輪廓走」的邏輯就變成「朝柱子衝」。

解法分兩層：

  • 把所有黑色輪廓包成一個 super bounding box，瞄準的是整體的中心（也就是門縫），而不是任何一根柱子
  • 門縫寬度撐滿畫面 70% 時，代表已經在門前——方向盤打正、全速衝刺，不再修正（這時候任何轉向都是自找麻煩）
  • 視野裡只剩一根柱子且高度超過畫面 60% 時，進入單側排斥：看見左柱向右閃、右柱向左閃

v4.0：左柱出現在畫面右邊——狀態混淆與空間記憶

v3 有個致命假設：柱子在畫面左半邊就是左柱。但如果車體已經嚴重偏移，左柱完全可能出現在畫面右側——這時排斥方向就反了，機器人朝錯的方向逃，越逃越迷航。這種「同一個觀測對應多種真實狀態」的問題，就是 state aliasing。

破法是給機器人一份短期空間記憶：memory_gap_x 記住最後一次看到完整門縫時的 x 座標。之後只剩單柱時，不再用畫面中心判斷左右，而是問記憶：「這根柱子在記憶中的門縫哪一側？」

同一版還加了虛擬目標：中距離看到單柱時，不等撞近才排斥，而是在柱子旁 250px 處憑空生成一個虛擬門縫座標，讓 P 控制朝虛擬點走——路徑提早畫出一條平滑的入彎弧線。

v5.0：記憶要在潛意識層更新

v4 還剩兩個殘缺。一是冷啟動偏差：遠距離時整座拱門糊成一小塊，會被誤判成「單柱」而寫入錯誤記憶。解法是加一條判斷——黑塊高度不到畫面 35% 就視為「遠方的完整拱門」，直接當成第一印象記憶。

二是結構性的：記憶更新原本寫在導航狀態裡，機器人一旦進入避障狀態，就停止更新對拱門的記憶——繞完障礙物出來，拿著過期的記憶亂走。最後一版把記憶更新抽離到所有決策之前：不管當下在避障還是巡邏，只要畫面裡出現拱門特徵，就先非同步更新門縫座標，再進入行為決策。除錯時把這條記憶畫成一條藍色垂直線疊在畫面上，一眼就能看出「大腦以為門在哪」。

# 每一幀、任何狀態下都先跑：背景記憶更新
if len(valid_black_contours) >= 2:
    self.memory_gap_x = (x_min + x_max) // 2      # 看得到門縫：更新
elif single_contour_height <= height * 0.35:
    self.memory_gap_x = contour_center_x          # 遠方整體拱門：第一印象
# ……然後才是避障 / 導航 / 巡邏的決策

後日談與心得

後來又做了一個進階版：換成六狀態的顯式狀態機（search → scan → align → drive → door，加上 wall_follow 和 reposition 兩個補救狀態），用連續 8 幀確認來抗雜訊、用「強制走完再說」解掉狀態間的死循環。架構更工整，但核心的幾課全是這五個版本教的：

  1. 失敗驅動的迭代比功能驅動誠實——每一版的需求都是上一版撞出來的，不是想出來的
  2. 觀測不等於狀態。純視覺下同一幀畫面可能對應多種真實處境，記憶（哪怕只有一個 x 座標）就是打破歧義的最小武器
  3. 感知要跟決策解耦。v5 最重要的改動不是任何演算法，是把「更新記憶」從狀態機裡搬出來——潛意識不該被當下的行為打斷
