Cole Medin：agent 寫 code 的速度，已經快過我驗證的速度

今天 Cole Medin 還有另一支很短的：My AI Agents Write Code Faster Than I Can Verify It。

一樣先說，這支一分多鐘，是 Sonar 的合作影片，我是看字幕整理的，那份報告本身我還沒讀。

他講了什麼

Sonar 調查了一千多位開發者跟工程主管，76% 說自己產生 AI 程式碼的速度比驗證還快。Cole 說他自己也是這樣，工廠整天在開 PR，他大部分時間都花在判斷能不能信任這些東西。

讓他最擔心的一個數字：AI 的程式碼越寫越好，檢查它的人反而變少了。說「每次 commit 前都會檢查」的人比一年前少。擔心「AI 寫得太漂亮、bug 很難看出來」的比例從 31% 升到 42%。因為還能漏過去的 bug，都是那種看起來完全合理的。

報告裡有一條公式，他說他很喜歡：

code confidence = intent × guardrails × verification × evidence

因為是乘法，只要有一項是零，整體就是零。context 給得再好，沒有獨立的驗證，送出去的還是沒檢查過的程式碼。他自己的做法是 agent 想寫什麼都可以，但沒有通過一個 agent 自己控制不了的檢查，就不能 merge。

我的想法

「寫得越好，越少人檢查」這件事我有點心虛。東西看起來順，我也常常就滑過去了，尤其是文字類的，讀起來通順就以為內容對。

乘法這個說法我覺得蠻好記的。我比較常犯的是前面兩項做很多，規則寫一堆、說明寫很細，最後那一步驗證卻偷懶。照這個公式，前面做再多也是白做。

報告有空再去翻，看那些數字是怎麼問出來的。
