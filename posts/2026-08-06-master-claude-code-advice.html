Cole Medin 新片：Claude Code 之父叫大家做的事，有點反直覺

同一天的第二支：The Creator of Claude Code Said to Do What Now?!。標題在賣關子——Claude Code 的創造者叫你做什麼？！影片我還沒看，但 Boris Cherny 這幾個月的公開發言我大致有跟到，先把背景整理起來，順便猜猜 Cole 在驚訝什麼。

Boris 最近說了什麼

  • 七月中他發了一篇 Steps of AI Adoption，把團隊採用 AI 分成五個階段，從完全不給用，一路到 AI-native——同時跑上千個代理的那種。
  • 更早的訪談裡他說自己已經八個月沒有手寫過程式，平常做的事是「管理」幾百到上萬個代理幫他寫。
  • 最猛的是這條：Opus 5 出來之後，他們把 Claude Code 的系統提示砍掉八成，結果模型表現反而更好。他的論點是，現在的前沿模型被「為上一代弱模型設計的產品」綁住了，應該給它們更難的任務、更少的指令。

所以 Cole 標題裡那個「叫你做什麼？！」，八九不離十就是「別再微觀管理你的 AI」這件事——少寫指令，放手讓它跑。

我自己的疑問

老實說，這說法我一半信一半不信。信的部分：規則寫太細反而綁手綁腳，這我自己碰過，改幾行提示詞省下的力氣有時候還不如直接把任務講清楚。不信的部分：Boris 人在 Anthropic 裡面，用的是最好的模型和內部工具，他說放手就好；一般人在自己的專案上放手，風險完全不是同一個量級。代理亂跑一通、刪錯東西的故事又不是沒聽過。

有趣的是，Cole 上個月才拍過一支講怎麼安全地跑 coding agent 的片（我的筆記），這支跟那支放在一起看應該蠻有意思：一邊教你圍柵欄，一邊叫你放手。他自己怎麼調和這兩件事，是我最想看的部分。

這支我會排在片債的前面，跟自己的工作流直接相關。看完再回來補。
